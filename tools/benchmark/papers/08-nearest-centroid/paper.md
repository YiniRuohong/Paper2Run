# 迷你论文 08：方差不等与先验偏斜下的最近质心分类（合成数据）

## 任务
二分类：2 维高斯特征，两类方差悬殊且先验 75/25 偏斜，预测
类别 0/1。

## 数据生成
- seed: 20261008（单条 random.Random 流，先训练集后测试集）
- 训练 200 条 / 测试 80 条；P(class=1) = 0.25。
- 类 0：中心 (0,0)，两维独立 N(center, 0.25^2)；类 1：中心
  (1.2,1.2)，两维独立 N(center, 1.3^2)。
- 难度设计——方差不等 + 先验偏斜：宽类（类 1）只占 25% 且
  sigma 是紧类的 5 倍，其质心噪声大、被拖向重叠区，最近质心
  对紧类边界系统性失准。

## 方法
逐类求均值质心；测试点按欧氏距离归入最近质心（平方距离并列
判 0 类）。

## 指标与声称区间
- 指标: accuracy（测试集 80 条）
- 论文声称区间: [0.81, 0.93]

## 复现约定
脚本自包含、仅标准库；输出 predictions.json / labels.json / metrics.json；
同 seed 重复运行逐字节可复现。
