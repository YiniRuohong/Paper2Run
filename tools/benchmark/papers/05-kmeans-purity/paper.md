# 迷你论文 05：重叠高斯簇上的 k-means 聚类纯度（合成数据）

## 任务
三聚类：把 3 个重叠的二维高斯簇聚成 3 类，以簇纯度（purity）
对照真实类别评估聚类质量。

## 数据生成
- seed: 20261005（采样用单条 random.Random 流；k-means 初始化用
  seed+1 的独立流）
- 共 150 点：三簇各 50 点，中心 (0,0)、(0.9,0.15)、(0.45,0.85)，
  两维独立 N(center, 0.45^2)。
- 难度设计——簇重叠：中心两两距离约 0.9 而 sigma=0.45，簇间大量
  交叠，纯度远离 1。

## 方法
Lloyd 算法：k=3，初始质心从数据点中 seeded 随机抽取；每轮按最近
质心分配（并列取小索引）后重估质心（空簇保留原质心）；60 轮或
分配不再变化即停。纯度 = 各簇内真实类别的众数计数之和 / 总点数，
在全量聚类集合上计算（train==eval，无泛化主张）。

## 指标与声称区间
- 指标: purity（全量 150 点）
- 论文声称区间: [0.70, 0.83]

## 复现约定
脚本自包含、仅标准库；输出 predictions.json（簇 id）/ labels.json
（真实类）/ metrics.json；同 seed 重复运行逐字节可复现。
