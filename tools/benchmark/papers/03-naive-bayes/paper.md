# 迷你论文 03：强相关特征下的高斯朴素贝叶斯（合成数据）

## 任务
二分类：2 维强相关高斯特征，预测类别 0/1。

## 数据生成
- seed: 20261003（单条 random.Random 流，先训练集后测试集）
- 训练 200 条 / 测试 60 条；两类各半。
- 潜变量 a,c 独立标准正态；b = 0.9*a + sqrt(1-0.81)*c（即
  corr(a,b) = 0.9）。特征 = (μ_c + a, μ_c + b)，μ_c = -1.2 或 1.2。
- 难度设计——特征强相关（rho=0.9）：违反朴素贝叶斯的条件独立
  假设，共享证据被重复计入、后验过度自信。

## 方法
逐类估计每维均值与方差（方差下限 1e-6），对数空间打分：
log prior + 各维高斯对数似然之和；取分数高者。

## 指标与声称区间
- 指标: accuracy（测试集 60 条）
- 论文声称区间: [0.79, 0.91]

## 复现约定
脚本自包含、仅标准库；输出 predictions.json / labels.json / metrics.json；
同 seed 重复运行逐字节可复现。
