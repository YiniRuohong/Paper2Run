# 迷你论文 06：离群值污染下的 OLS 线性回归 R²（合成数据）

## 任务
一元线性回归：拟合 y = f(x)，在干净测试集上以 R² 评估。

## 数据生成
- seed: 20261006（单条 random.Random 流，先训练集后测试集）
- 训练 160 条 / 测试 60 条；x ~ U(0,4)，
  y = 1.8x + 0.6 + N(0, 0.7^2)。
- 难度设计——离群值污染：训练集中 6% 的点的目标值被 +9 抬高
  （测试集干净），把最小二乘直线拖离真实关系。

## 方法
闭式普通最小二乘：slope = (n·Sxy − Sx·Sy)/(n·Sxx − Sx²)，
intercept = (Sy − slope·Sx)/n；在干净测试集上计算 R² =
1 − SSE/SST。

## 指标与声称区间
- 指标: r2（测试集 60 条；预测值与标签均为浮点数）
- 论文声称区间: [0.67, 0.79]

## 复现约定
脚本自包含、仅标准库；输出 predictions.json / labels.json /
metrics.json（本任务 prediction/label 为 float，是基准套件对回归
任务的显式例外约定）；同 seed 重复运行逐字节可复现。
