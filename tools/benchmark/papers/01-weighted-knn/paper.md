# 迷你论文 01：尺度失衡特征上的加权 k-NN 分类（合成数据）

## 任务
二分类：给定 2 维合成特征（x1 与 x2 尺度相差约 3 个数量级），预测类别 0/1。

## 数据生成
- seed: 20261001（单条 random.Random 流，先训练集后测试集依次采样）
- 训练 120 条 / 测试 30 条；两类各半。
- 类别 c∈{0,1} 均匀抽取；特征中心 μ_c = (-1.3,-1.3) 或 (1.3,1.3)，
  两维独立 N(μ_c, 1.2^2)。
- 原始特征 = (x1_raw * 50.0, x2_raw * 0.02)。
- 难度设计——特征尺度失衡：欧氏距离被 x1 支配，未标准化的 k-NN
  会显著退化；论文方法必须先做标准化。

## 方法
训练集统计量做 z-score 标准化 → 逆距离加权 5-NN 多数投票
（权重 1/(d+1e-9)，加权平票判 0 类）。

## 指标与声称区间
- 指标: accuracy（测试集 30 条）
- 论文声称区间: [0.84, 0.95]

## 复现约定
脚本自包含、仅标准库；输出 predictions.json / labels.json / metrics.json；
同 seed 重复运行逐字节可复现。
