# 迷你论文 02：类别不平衡下的加权逻辑回归（合成数据）

## 任务
二分类：2 维高斯特征，少数类占比仅 10%，预测类别 0/1。

## 数据生成
- seed: 20261002（单条 random.Random 流，先训练集后测试集）
- 训练 200 条 / 测试 80 条；P(class=1) = 0.10。
- 类别 c=1 时特征中心 (1.5,1.5)，c=0 时 (0,0)；两维独立 N(μ_c, 1.0^2)。
- 难度设计——类别不平衡：全部预测多数类即得 0.90 accuracy，
  无加权的训练会忽视少数类；论文方法必须做类加权。

## 方法
类加权交叉熵（权重 w_c = n / (2 * count_c)），全批梯度下降
500 轮、学习率 0.5；预测 z>0 判类别 1。

## 指标与声称区间
- 指标: accuracy（测试集 80 条）
- 论文声称区间: [0.82, 0.93]
（论文同时诚实指出：不平衡下 accuracy 是弱指标。）

## 复现约定
脚本自包含、仅标准库；输出 predictions.json / labels.json / metrics.json；
同 seed 重复运行逐字节可复现。
