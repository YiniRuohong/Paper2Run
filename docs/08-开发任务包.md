## 📋 T01 合约、持久化与串行装配

**目标与批准实现：** 建立单一 Pydantic schema、资源/状态枚举、canonical JSON、金额/单位、数据库约束和 UnitOfWork。先实现最小 DB job/事件事务接口与预算预留/结算基础，后续包只消费端口。

**允许目录（拟实现契约）：** `packages/contracts/`、`packages/persistence/`、`packages/orchestration/budget/`、`scripts/dev/`；根 `Makefile`、`pyproject.toml`、`uv.lock`、`package.json`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`。共享工具配置须放上述声明文件，不默认获得其他根文件写权。

**公共装配独占路径：** `services/api/p2r_api/{__init__.py,main.py,settings.py,registry.py,health.py}`、`services/worker/p2r_worker/{__init__.py,main.py,settings.py,registry.py}`、`services/runner/p2r_runner/{__init__.py,main.py,settings.py,registry.py}`；`apps/web/{package.json,index.html,vite.config.ts,vitest.config.ts,playwright.config.ts,tsconfig*.json}`、`apps/web/src/{main.tsx,app.tsx,env.d.ts}`。后续包只提装配请求，T01 串行处理；新增入口须主 Agent 先批准。

**测试归属：** `tests/unit/t01/`、`tests/integration/t01/`、`fixtures/t01/`。各 feature 业务逻辑不放入公共装配文件。

**禁止边界：** 不实现业务路由、模型算法或容器执行；不增加 Redis/Celery/LangGraph/Kubernetes；不手改生成 TypeScript。若需更换 canonical 库或新增持久实体，先交主 Agent 审查。

**交付：** OpenAPI 3.1、recipe/SSE/descriptor JSON Schema、ModelRequest/ModelResult 边界模型、TS 类型、跨语言 hash fixture；Alembic 初始迁移与受控测试数据；原子 run/job/event 和预算账本接口；命令分派与安全模式检查。

**检查（未来契约）：** `make contracts-check`、`make test-unit TASK=T01`、`make test-integration TASK=T01 MODE=local-cpu`；临时库验证升级，不以清空真实库验证迁移。

**成功条件：** 金额非浮点、revision/确认不可变；活动 run、event seq、operation_key/幂等键约束生效；并发预留不超额、未知费用不释放为零；生成快照一致。无真实 GPU/模型参与该包验收。

**依赖与交接：** 无上游代码依赖；向后续包交付只读 schema/端口版本。T01 保留后续串行合约更新和装配职责，每次变更重跑 contracts-check 并通知消费者。

## 📋 T02 邀请登录、项目与权限 API

**目标与批准实现：** 实现一次性邀请、opaque 会话、CSRF/Origin、owner/editor/viewer、项目归属和统一错误/幂等。公共 API 使用 `/api/v1`，跨项目资源 404，项目内禁用操作 403。

**允许目录（拟实现契约）：** `packages/identity/`、`packages/projects/`；`services/api/p2r_api/routes/{auth,projects,capabilities,operations}/`、`services/api/p2r_api/dependencies/auth/`、`services/api/p2r_api/admin/`、`scripts/admin/`。

**测试归属：** `tests/unit/t02/`、`tests/integration/t02/`、`fixtures/t02/`。后续资源路由复用本包权限依赖，不复制查询逻辑。

**禁止边界：** 不开放公开注册、社交登录或任意角色修改接口，不写固定演示密码；不修改公共 schema/迁移，不在请求内执行后台计算，不处理生成代码。

**交付：** 会话 API、项目 CRUD/成员审计、能力与 operation 归属查询；管理员 `invite-create`/`member-set`；删除先进入 deleting 并拒绝新任务，后续停止与清理由生命周期端口衔接。

**检查（未来契约）：** `make test-unit TASK=T02`、`make test-integration TASK=T02 MODE=local-cpu`、`make contracts-check`。

**成功条件：** 两个邀请账户互不越权；viewer 无法发起收费或导出创建；session 只存 hash，禁用/过期/注销有效。登录不缓存/重放 session secret；响应丢失先 `/api/v1/auth/me`，失败由管理员撤销未知会话并重发邀请，不凭幂等键取回 secret。除登录设置 cookie 外，秘密不进响应正文/日志；删除未确认停止前不宣称完成。

**依赖与交接：** T01；交付所有后续路由必须使用的 actor/project 授权端口、管理员入口及不含秘密的审计格式。

## 📋 T03 Runner 隔离、签名租约与产物回收

**目标与批准实现：** Runner 私网 mTLS 主动领取 execution，以 canonical descriptor + Ed25519、公钥 allowlist、注册能力交集、epoch/租约驱动固定 recipe+phase；本机仅可信 CPU smoke。

**允许目录（拟实现契约）：** `services/runner/p2r_runner/{leases,sandbox,artifacts,health,reaper}/`、`packages/execution/`、`packages/artifacts/{storage,staging,integrity}/`；`services/api/p2r_api/routes/internal/`、`services/worker/p2r_worker/stages/execution/`、`sandbox/images/`；`recipes/cv_classification/<id>/<version>/runtime/` 与该版本的 `image-manifest.json`，不含受保护评测部分。

**测试归属：** `tests/unit/t03/`、`tests/integration/t03/`、`fixtures/t03/`；镜像仅维护者代码，基础镜像变更仍需主 Agent 审查。

**禁止边界：** 无任意 argv/shell/docker flags、公网 Runner、API Docker socket；模型 Secret 仅 Worker，DB 和服务端对象存储凭据不得进入 Runner/容器。容器也无 Runner token、短期对象传输能力或评测标签；不修改评测器或数据 split，不将唯一 watchdog 放在主循环内。

**交付：** 领取/心跳/事件/产物 init/complete 协议；code_ro、train_data、prediction_inputs、work、outputs 隔离；资源限额及独立 reaper 按受控容器标签、租约 TTL/墙钟回收；JSONL 日志、冻结后校验与 staged 上传；已受理 execution 对账。宿主监管模板交 T10，独立测试驱动器先验收进程崩溃清理。

**检查（未来契约）：** `make test-unit TASK=T03`、`make test-integration TASK=T03 MODE=local-cpu`、`make contracts-check`。GPU 隔离另在授权 remote-gpu 环境检查，CPU 通过不能替代。

**成功条件：** 路径穿越/软链接/联网/秘密读取被阻断；非 root、只读根和限额有效；旧 epoch 不能完成，同 hash ACK 重试不重复启动。杀死 Runner 主循环后独立 reaper 仍在 TTL 加宽限内停容器；停止确认才释放槽位，失联不立刻重发执行，监管失效拒绝新 execution。

**依赖与交接：** T01、T02；固定维护者小模型真实产出权重/预测与退出码后交 T04。实际 GPU 兼容性未验证时明确保留阻塞，不改为 Mac CUDA 承诺。

## 📋 T04 独立评测、数据协议与比较资格

**目标与批准实现：** Worker 可信域纯程序读取预测和受保护标签；不 import 生成模型、不采用 stdout/候选 metrics。比较先检查原文目标、模式、训练/评测协议和证据，再计算冻结公式。

**允许目录（拟实现契约）：** `packages/evaluation/`、`packages/experiment/comparison/`、`services/worker/p2r_worker/stages/metrics_verify/`；`recipes/cv_classification/<id>/<version>/{data,evaluation,tests}/`。外部数据下载或许可变更不属于自动授权。

**测试归属：** `tests/unit/t04/`、`tests/integration/t04/`、`fixtures/t04/`；fixture 要标来源和用途，不把示例分数放生产真值。

**禁止边界：** 不让预测箱拿标签，不加载 pickle 或生成代码，不改参考值/容差/评分权重迎合结果；不触碰 T03 runtime 和镜像文件。

**交付：** 限长 JSONL 预测解析、ID 覆盖/重复/有限值/类别映射检查、确定性 metrics 与 hash；smoke/scaled 不可比规则，参考为零时相对变化 null，结构项分母固定。

**检查（未来契约）：** `make test-unit TASK=T04`、`make test-integration TASK=T04 MODE=local-cpu`、`make contracts-check`。

**成功条件：** 同合法预测得同结果，漏样本/NaN/伪造 metrics 被拒；不可比时 metric_match/total 为 null，不将缺失置零；受保护标签不出现在预测挂载、事件或下载清单中。

**依赖与交接：** T01 和 T03 冻结的预测契约；提供可比性预检给 T05，VerifiedMetrics 与 evaluator_version 给 T09。新增格式须经 T01 串行更新 schema。

## 📋 T07 独立 Worker 恢复、运行快照与 SSE

**目标与批准实现：** 将阶段处理器接入独立 DB 队列 Worker，短事务领取、租约/fencing、同事务 state/event/next job；先对账执行再恢复；持久事件驱动快照与 SSE，不用内存队列作事实源。

**允许目录（拟实现契约）：** `services/worker/p2r_worker/{queue,runtime,reconciliation}/`、`services/worker/p2r_worker/stages/project_purge/`、`packages/orchestration/{events,recovery,cancellation}/`；`services/api/p2r_api/routes/{run_queries,run_events,attempts}/`。公共 main/注册表由 T01 串行装配。

**测试归属：** `tests/unit/t07/`、`tests/integration/t07/`、`fixtures/t07/`；故障注入仅在本包临时库/测试 Runner 环境。

**禁止边界：** 不借助 Redis/Celery，不长期持 DB 锁等训练；不把 Runner event_no 当 run seq，不允许旧租约覆盖正式产物，不自动释放未知费用。

**交付：** 领取/续租/恢复与最终清理、运行/attempt 原子快照、SSE 去重重放、日志限速；409 EVENT_CURSOR_EXPIRED、会话过期和慢客户端处理；report 状态与 run 终态独立。

## 📋 并行、排期与砍范围原则

- 默认串行。仅主 Agent 确认允许目录、测试临时库/端口/产物域互不重叠后才并行；共享运行服务或同一测试库也属于冲突，不能只看源码不同。

## 📋 接口验收矩阵

下列接口路径与检查入口均为拟实现契约，当前不存在不可直接运行；鉴权写请求沿用 cookie/CSRF 与规定幂等头，登录仅做 Origin/限流和一次性兑换，不套通用幂等响应重放。矩阵编号用于关联测试证据，不代表已有测试。

| 编号 | 接口/场景 | 关键断言 | 责任包 |
|---|---|---|---|
| I01 | `/api/v1/auth/session`、`/api/v1/auth/me` 与子资源权限 | 邀请不可重放；响应丢失先查会话、失败管理员重发；不缓存 secret；CSRF/Origin 拒绝；跨项目 404、项目内禁用 403，viewer 不收费 | T02 |
| I02 | `POST /api/v1/projects/{id}/papers` | PDF/arXiv 新建 202；内容幂等；超限 413/非 PDF 415；未同意外传/私网 URL 拒绝 | T02、T05 |
| I03 | revision 保存、`/api/v1/spec-revisions/{id}/confirm` | 旧 base/head/hash/policy 冲突；blocking issue 不可接受消除；同确认请求幂等，草稿不等于可启动 | T01、T05 |
| I04 | `POST /api/v1/projects/{id}/runs` | 同 key/body 不重复，同 key 异 body 409；并发仅一活动 run；未确认拒绝；账本预留不超卖 | T01、T06 |
| I05 | `/internal/v1` 领取/heartbeat/complete | mTLS 身份/能力/签名一致；旧 epoch 409；ACK 丢失同 hash 读回；错误 hash 不发布、不重复启动 | T03 |
| I06 | `POST /api/v1/runs/{id}/cancel` | 活动返回 202，终态返回原状态；取消/完成竞态一致，容器退出才释放槽位；失联明确停止待确认 | T03、T06、T07 |
| I07 | run 快照与 `/api/v1/runs/{id}/events` | 快照到 SSE 不漏；Last-Event-ID 优先、去重；cursor 过期建流前 409；会话恢复不用 query token | T07、T08 |
| I08 | prediction → metric → report | 漏/重复 ID、NaN、伪 metrics 拒绝；只由可信 evaluator 发 metric.verified；smoke/scaled 不可比 total=null | T04、T09 |
| I09 | report、exports、artifact/text/download | report 准备中/创建导出返回 202，text/download 仅授权 finalized 可读；PDF 局部失败不清其他格式；operation/attempt/export 查父项目，Secret 不出包 | T02、T09 |
| I10 | capabilities + mock/live/replay 页面 | backend/data_mode 匹配；mock 无模型/容器，replay 真实历史只读；新 live 上传生成新 run，日志/HTML/命令不可执行 | T08、T10 |

具体命令由各责任包调用前述 unit/integration/e2e 和 contracts-check；每条保留正向、负向与环境信息。跨包矩阵只能在全部相关模块接好后判通过，不以单个 mock 用例替代。

## 📋 Definition of Done 与最终审查

1. 每包只改获准路径；公共变更有 T01 串行记录，依赖锁和合约版本可追溯；无未批准的技术栈/功能扩展。
2. 指定静态检查、单元/集成/浏览器检查具备真实结果；命令不存在、环境缺失、失败和跳过分别记录，文档设计检查不算产品测试。
3. 新上传 → 有来源解析 → 精确确认 → 新代码执行 → 独立评测 → 报告/下载完成一次真实闭环；未通过则列阻塞，不写“端到端完成”。
4. 新旧 revision/run/attempt/execution 与 hash 链可追溯；语义修改新建 revision/派生 run，预算和五次修复不可重置。
5. 负面测试覆盖越权、秘密泄露、SSRF、恶意 HTML、路径穿越、断网、超时/OOM、旧租约、ACK 丢失、伪造指标和缺失预测。
6. 关闭页面任务继续，刷新/重连/Worker 重启可恢复；取消/删除等待实际停止，失败也交付诊断，不伪称停止计费。
7. 四模式、三实验模式和数据来源始终可辨；没有真实历史就没有 replay 成果；smoke/scaled 和不可比较结果不输出误导性总分。
8. 导出数字与固定评测一致，finalized/权限/许可/hash 验证通过；缺失数据和未重跑条件明确披露，不声称任意机器必然数值一致。
9. 授权部署与冷启动、备份恢复、回滚逐项演练或明确未执行；Qwen/GPU/价格/成功率只引用实际记录，预算目标不当实测结论。
10. 实施者回报改动、命令结果、未验项、偏差与风险；主 Agent 亲自复核后接受。未经操作者授权，不把开发验收自动升级为发布、资源消费或比赛提交。
