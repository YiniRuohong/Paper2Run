# 任务页：中间栏只放结论，过程在抽屉里看

日期：2026-11-06 · 范围：`apps/web` 任务页（`#/task/<id>`，第 05–09 步）

## 为什么

任务页中间栏把所有卡片一次铺满：结局、结论、指标、证据完备性、候选复核、完成门槛、执行观测、模型叙述、用量、配置、原始事件。用户要的是：中间栏只放结论和图表；想看某一步的过程时，点左栏那一条，弹出这一条的简要过程。参考 apevonscience.com 产品演示：点时间线里的一条命令，右侧滑出抽屉，只显示「命令」和「输出」。

## 目标

- 中间栏默认只放：实时 / 结局卡、指标、图表，以及需要用户动手的卡片。
- 点左栏任一条子步骤，从右侧滑出抽屉，显示这一条的过程。
- 第 08、09 步和「任务详情」的过程性内容都从抽屉里看。

## 不做

- 左栏不改：结构、文字、图标、展开收起都保持现在的样子，只改点子步骤后发生什么。
- 配色不改：沿用现有的颜色和组件样式。
- 后端不改：抽屉内容全部来自现有的任务、事件和文件接口。

## 反目标

- 抽屉不能把程序判定和模型叙述混在一起：「模型叙述（不是执行证据）」等现有标注原样保留。
- 不能让任何结论从中间栏消失后只在抽屉里出现：结局和结论一直在中间栏。

## 做法（已选 A）

- **A. 右侧覆盖式抽屉（选定）**：从右边滑出，盖住文件栏，左栏和中间栏变暗；点 ✕、按 Esc 或点暗处关闭；点左栏另一条时直接换内容。中间栏始终停在结论上。代价：抽屉开着时看不到文件树。
- B. 中间栏内切换：点左栏后中间栏换成过程，顶部「← 返回」。文件树不被遮挡，但每看一条都要离开结论再回来。
- 中间栏原地展开：又回到全部堆叠，不考虑。

## 中间栏（默认）

从上到下：

1. 需要用户动手的卡片，照常：错误（一句话 + 折叠的原始错误）、安全终止、暂停 / 停止说明、需要恢复、方案审批。
2. **实时 / 结局卡**：
   - 未结束：虚线框卡片，一行状态（运行中 · 第 n / 9 步 · 当前步骤名），一行大字「正在 / 最近进度：Pi 最新自报进度」，一行「已执行 N 步操作」。「按事件归纳」标记保留。
   - 有报告后：现有的结局卡和结论卡（程序判定）。
3. 指标（现有统计格）。
4. 图表（现有 `FiguresView`）。
5. 追加指令：只在任务未结束时显示。

移出中间栏：证据完备性、候选卡、「详细记录」整个折叠区、论文 / 目标 / 模型 / 任务摘要表。

## 抽屉

**外观**：在三栏网格内绝对定位，盖住文件栏，宽度约 520px（窄屏时盖住中间栏右侧部分）；其余区域加半透明遮罩。头部：步骤标签（「步骤 06 · 编写与执行」）+ 标题 + ✕。内容可滚动。

**行为**：一次一个；点左栏另一条换内容；Esc / ✕ / 遮罩关闭；打开时焦点进抽屉，关闭后回到被点的那一行；抽屉对应的那一行保持选中高亮（现有 `is-on`）。任务轮询刷新时内容跟着更新（比如命令还在运行，结束后显示输出）。

**内容（按左栏条目类型）**：

| 左栏条目 | 抽屉内容 |
|---|---|
| 命令（execute / background / status / logs） | 「命令」深色代码块；「输出」深色代码块（stdout，stderr 单独一块，有截断时标出）；退出码与状态 |
| 其他工具调用（write、register_artifact、propose_protocol 等） | 参数与结果（可读的键值，复杂值用 JSON 代码块）；出错时一句话错误 |
| Pi 自报进度 | 阶段名与原文，标注「模型叙述」；其下的工具调用列表，点了换成那一条 |
| 专家调用 | 现有专家调用的单条内容：专家、任务类型、问题、回复、状态 |
| 冻结证据 | 名称、类型、轮次、SHA256、来源路径；「在中间栏打开文件」按钮（沿用现有文件预览） |
| 其他事件（预算、复核、报告生成等） | 事件说明与时间，原始载荷折叠 |

**第 08、09 步标题**：点标题仍然像现在一样展开收起；同时打开这一步的抽屉：
- 08 候选与复核：证据完备性 + 候选与独立复核（现有 `EvidenceCard`、`CandidateCard`）。
- 09 报告：完成门槛、执行观测、模型叙述、局限（现有 `ReportDetails`）。

**任务详情**：标题行状态标签旁加一个「任务详情」按钮，打开抽屉：论文 / 目标 / 模型 / 任务 ID、用量、科研专家调用、Skills 快照、任务配置快照、原始事件流（折叠）。

## 实现上已定的部分

- `Workbench` 增加可选的 `drawer`（抽屉内容与关闭回调）和 `onOpenItem(stageId, item)`；提供 `onOpenItem` 时子步骤点击走它，而不是打开文件。不提供时行为不变（准备阶段页面不受影响）。
- `WbStageItem` 增加一个不透明的 `ref` 字段，`stages.ts` 生成条目时写入（如 `tool:<调用 id>`、`event:<序号>`），任务页据此从事件里取内容。
- 抽屉组件放在 `ui/workbench/`，各类内容放在 `features/autonomous/`。
